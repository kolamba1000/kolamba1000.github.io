Ограничения

Ограничения дизайна

  • id без названия

    Точка продаж показана как id, например 12345. Названия магазина в интерфейсе нет

  • Только направление

    Отклонение факта от прогноза показано числом и цветом. Направление задаёт дизайн

  • Разная детализация

    Прогноз показан по дням. Факт показан по неделям. Дизайн сводит их в одной таблице

  • Без формулы

    Оценка качества 1–⁠10 показана как есть, без формулы расчёта
